# SkillSwap

SkillSwap is a responsive front-end concept for peer-to-peer learning. It gives university students a simple place to discover skills, share what they know, save learning interests, and connect with other learners at no cost.

## Features

- Browse student-led skills and learning paths
- Explore community and profile views
- Save skills for later
- Login and sign-up interface flows
- Responsive navigation and theme toggle
- Browser-based demo data for a server-free prototype

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

No install or build step is required.

1. Clone the repository.
2. Open the project folder in VS Code.
3. Start `index.html` with the Live Server extension, or serve the folder with any static-file server.

## Project structure

```text
SkillsSwap/
├── css/       # styles
├── images/    # visual assets
├── js/        # app data and client-side behavior
└── *.html     # application pages
```

## Status

This is a front-end prototype. Authentication, matching, and messaging are demonstration flows and are not connected to a production backend.
